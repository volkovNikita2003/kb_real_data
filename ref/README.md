# Эталонный расчет `test_17_07_26_kmk_15`

Директория содержит исходные скрипты и результаты расчета, с которыми должна
сравниваться автоматизированная реализация. Полный расчет запускается из любой
рабочей директории:

```bash
./ref/run.sh
```

Основные эталонные данные:

- `calibration_auto/calibration_reference.txt` — итоговые параметры калибровки;
- `calibration_auto/*_calibration_signal.txt` — обработанные калибровочные
  сигналы и их аппроксимации;
- `darl-kmk-15-signal/matrix-*.npz` — аппаратная матрица;
- `darl-kmk-15-signal/b_*.txt` — сигналы заданных распределений;
- `darl-kmk-15-signal/background_signal_laser_*.txt` — модельный фон;
- `restore_*/*/reference_*` — сигналы, полные результаты обратной задачи,
  GCV-кривая и выбранный коэффициент регуляризации.

Текстовые численные результаты сохраняются с 17 значащими цифрами. При
сравнении вычислений следует использовать численный допуск, а не побайтовое
совпадение: результат может незначительно зависеть от версий NumPy, SciPy и
BLAS/LAPACK.

В `experiments/test_17_07_26_kmk_15` те же исходные данные разложены по новой
структуре. Файлы `input_parameters` фиксируют все параметры, которые описывает
текущая схема YAML. Параметры построения HDR-сигнала старого `restore.py`
(`l2h`, `after_hdr`/`per_exposure`, пороги 10/12/240 и sigma 5) пока не входят
в эту схему; их необходимо добавить при автоматизации этапа восстановления.

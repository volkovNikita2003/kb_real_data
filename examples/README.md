# Примеры входных параметров

В каталоге находятся четыре самостоятельных набора:

- `minimal/` — камера и линейка, во всех обязательных YAML-файлах указаны
  только обязательные поля;
- `complete/` — камера и линейка, указаны все поля, поддерживаемые текущей
  версией программы;
- `camera_only/` — пример эксперимента только с камерой;
- `camera_line/` — компактный практический пример с камерой и линейкой.

В `minimal/` отсутствует `measurements/`, поскольку ожидаемое распределение
измерения является необязательным и не требуется для построения матрицы,
численного контроля или восстановления реального сигнала.

В `complete/` файл `measurements/kmk_15.yaml` включён, чтобы показать полный
формат и возможность расчёта ожидаемого сигнала.

Значения в примерах демонстрационные. Перед обработкой реального эксперимента
необходимо заменить параметры частиц, среды, положения линейки и другие
экспериментально зависимые значения.

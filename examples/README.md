# Примеры входных параметров

В каталоге находятся пять наборов параметров:

- `minimal/` — камера и линейка, во всех обязательных YAML-файлах указаны
  только обязательные поля;
- `complete/` — камера и линейка, указаны все поля, поддерживаемые текущей
  версией программы для камеры и линейки;
- `camera_only/` — пример эксперимента только с камерой;
- `camera_line/` — компактный практический пример с камерой и линейкой;
- `camera_line_side/` — камера, линейка и девять боковых детекторов, на основе
  `experiments/test_17_07_26_kmk_15_side`.

В `minimal/` отсутствует `measurements/`, поскольку ожидаемое распределение
измерения является необязательным и не требуется для построения матрицы,
численного контроля или восстановления реального сигнала.

В `complete/` файл `measurements/kmk_15.yaml` включён, чтобы показать полный
формат и возможность расчёта ожидаемого сигнала.

Значения в примерах демонстрационные. Перед обработкой реального эксперимента
необходимо заменить параметры частиц, среды, положения линейки и другие
экспериментально зависимые значения.

## Камера, линейка и боковые детекторы

В `camera_line_side/` сохранены примеры параметров эксперимента с боковыми детекторами:
таблица `data/comsol.txt` и сигнал `data/kmk_15/side/b.txt`.

В `general.yaml` боковые сенсоры имеют сторону `0.004` м и углы
`[5, 7.5, 10, 52.5, 55, 75, 110, 130, 165]` градусов. Девять строк бокового
сигнала соответствуют этому порядку. В `darl.yaml` и обоих профилях
восстановления присутствует пустая секция `detectors.side: {}`; вместе
с боковыми детекторами всегда включены камера и линейка. Калибровка
выполняется только для камеры и линейки.

Профиль `no_fm` восстанавливает распределение без повторного прямого
моделирования. Профиль `default` также рассчитывает сигнал восстановленного
распределения через `code_git`.

Восстановление сохраняет боковой сигнал в `reference_side_signal.txt` и его график в
`signal-side.png`. Если вместо исходных
данных используется `data/kmk_15/b.txt`, он должен содержать полный вектор
«камера → линейка → боковые детекторы»; отдельный `side/b.txt` тогда не читается.
